# APK Test Studio v0.1.0-beta.1

First Windows x64 preview.

- White Windows control sidebar.
- APK file picker, structural validation and optional package detection.
- Install and launch an APK on a dedicated Android 15 / API 35 virtual device.
- Home, Back, Recents, Rotate and Screenshot buttons.
- Independent ADB port, virtual device, local settings and RAM guard.

**Release asset:** APK_Test_Studio_Windows_v0.1.0-beta.1.zip

**Known limitations:** Google Android SDK must be installed separately; controller and Android Emulator use separate windows; Windows binary is unsigned; only one Android 15 x86_64 AVD supported; no test on a second Windows PC.

This is a **pre-release** and should be labeled as such on GitHub.
