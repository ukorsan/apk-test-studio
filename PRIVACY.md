# Privacy

The APK Test Studio controller has no telemetry, cloud backend, accounts or advertisements.

It stores SDK paths and the private AVD under %LOCALAPPDATA%/APKTestStudio, and may save user-requested screenshots there. APKs are never uploaded by the controller. Installation is performed through locally installed ADB only when explicitly requested.

These statements do not cover network behavior of the separately installed Android SDK/Emulator or the APKs being tested. Emulator execution is not a security sandbox guarantee.
